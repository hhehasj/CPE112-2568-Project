# systemC - CPE112-2568-Project
Mini task scheduler with undo history, with C Programming Language and TUI in Python

![Screenshot of systemc](TUI_screenshot.png)

---

## Origins

We wanted to create a demo of task scheduler, utilizing C Programming Language and Data Structure topics for out final project. The name "systemC" takes inspiration from an init system 'systemd', with a twist of... C language. We included a TUI using Python with Textual library.

## Installation

1. Clone the repository, run ```make```, and run the binary.
2. Activate the virtual environment: ```venv/scripts/activate``` or ```venv/scripts/activate.bat```
3. Go to 'frontend' directory and type ```python TUI.py```
